# 📱 NotiFy

NotiFy is a simple Android reminder application designed to help users remember important tasks, events, and activities.

## ✨ About the Project

NotiFy allows users to create reminders by selecting a specific **date and time**. When the scheduled time arrives, the app sends a notification along with a **sound 🔊**, helping users avoid missing important reminders.

The application also includes an **About Us** section that provides information about the application and its developers.

## 🚀 Features

- ⏰ Set reminders for a specific date and time
- 🔔 Receive notifications when a reminder is due
- 🔊 Notification sound alerts
- 📅 Easy date and time selection
- 📱 Simple and user-friendly interface
- ℹ️ About Us section

## 🛠️ Technologies Used

- Android Studio
- Kotlin
- Android SDK
- XML
- Android Notification System

## 🎯 Purpose

The main purpose of NotiFy is to provide a simple and convenient way for users to schedule reminders and receive timely notifications for important activities.
